# Behavioral parity matrix

Upstream reference: pstack 0.15.48, `cursor/plugins@41e40093` (see docs/pstack-analysis.md for
contract ids). "Eval" refers to scenarios in `evals/scenarios.ts`. Results are in
`evals/results/` and summarized in docs/verification.md. "Unit" refers to tests under `test/`.

Result values: **pass** (verified by the referenced check), **not machine-verified** (instruction
only, no deterministic check exists), **gap** (not implemented), **n/a** (does not apply to this domain).
